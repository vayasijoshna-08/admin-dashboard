# Admin Dashboard 

## Project Overview
This project is a responsive Admin Dashboard developed using **HTML, CSS, and Bootstrap 5**. It provides a clean and user-friendly interface to manage website information, users, products, orders, and other activities.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5

## Features
- Responsive Admin Dashboard
- Sidebar Navigation Menu
- Navigation Bar
- Dashboard Statistics Cards
- User Management Section
- Product Management Section
- Orders Overview
- Clean and Modern UI Design
- Mobile-Friendly Layout

## Project Structure

```text
Admin-Dashboard/
│
├── index.html
├── style.css
└── README.md
```

##  How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using Live Server or your browser.

The main purpose of this project is to improve my frontend development skills and gain practical experience in building responsive web interfaces using HTML, CSS, and Bootstrap.
